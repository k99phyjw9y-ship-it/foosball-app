# FoosManager

Web app for running foosball tournaments: **Singles**, **Doubles (BYP)**, **DYP**, and **Monster DYP**.

- Round generation & live score entry  
- Standings & playoff brackets  
- Week-over-week player stats  
- Works offline in the browser (data saved in localStorage)

## Live demo

After you enable GitHub Pages, your app will be at:

```text
https://YOUR_USERNAME.github.io/foosball-app/
```

(Replace `YOUR_USERNAME` and the repo name if different.)

## Local use

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8765
```

Then visit `http://localhost:8765`.

## iPhone

1. Open the GitHub Pages URL in **Safari**
2. Tap **Share → Add to Home Screen**

Data stays on the device (browser localStorage).
