# LCFC Manager v7.46

Lake Champlain Foosball Club manager and TV-board app.

## What's new in v7.46

### Teams filter
- Partnership leaderboard now requires **at least 5 matches together** (partners only).
- Pairs below that threshold are hidden from Teams stats and summary counts.
- Empty state and helper copy updated to match.

## From v7.45 — Teams statistics
- **Teams** section in Club Stats (beside Club DNA and Awards).
- Tracks all-time partnerships where the same two roster players appear on one side of a completed match.
- Partnership key = sorted player IDs (side order does not matter).
- Shows total, ranking, playoffs, W–L, win %, first/last played; player filter and match history.
- Best-of series count once per match, not per game.
- Sandbox, byes, unfinished, singles, and non-two-player sides excluded.
- Read-only — does not affect ranking points or brackets.

## Run the app

1. Download `index.html`.
2. Open in a modern browser, or replace the hosted app file.
3. Export a backup before replacing a live copy.
